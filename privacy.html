Privacy Policy — SoundOn Pin Assistant

Last updated: 2026-09-23

English

SoundOn Pin Assistant ("the App") is a private tool used solely by its owner to automate their own Pinterest account through the official Pinterest API v5.

  • Data accessed: information about the owner's own Pinterest account — boards, pins, and pin analytics — using OAuth access tokens granted by the owner.
  • How data is used: to create and organize pins, and to show the account's own performance metrics to the owner.
  • Data storage: access tokens and API responses are stored locally on the owner's device.
  • Sharing: no data is sold, shared, or transferred to any third party.
  • Revocation: the owner can revoke access at any time from Pinterest account settings; local data can be deleted on request.

日本語

本アプリは、所有者本人が自身のPinterestアカウントの運用を自動化するためだけに使用する個人用ツールです。取得するのは所有者自身のアカウントのピン・ボード・インサイト情報のみで、第三者への提供や販売は行いません。アクセストークンは端末内にのみ保存し、Pinterestの設定からいつでも連携を解除できます。
